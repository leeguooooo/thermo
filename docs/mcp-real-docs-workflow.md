三个检索结果都含正文及高亮副本；去掉高亮标签后，副本与对应正文逐字相同。首项是术语表，具体 Skill 指引在后面的结果中。这个样本说明 limit 小并不保证返回短，也不能由定义体积或握手成功推断业务返回开销。

投影保留原有顺序和三个 URL，用原始摘要去掉高亮标签、合并空白并截到最多 240 个 Unicode 码点。若只呈现投影加上选定原文，cl100k 参考计数之和是 840，原始两次返回之和是 12,367，表示差额约 93.2%。这是离线表示对照，没有新一轮任务执行或实际账单节省；本轮会话已经收到原始返回。投影可能丢失选页所需细节，更多任务仍需验证。

调用方可以保留原始响应供计量，在编排层只向模型呈现必要字段，再 fetch 选定原文。原始返回计量和实际呈现量应分开记录；不能把投影大小回填成工具原始返回，也不能把普通文本参考计数当成模型实际请求用量。
