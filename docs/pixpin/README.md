# PixPin 功能接入 Thermo

研究对象：本机 `/Applications/PixPin.app`，3.5.5.1。REA 打开的 universal Mach-O SHA-256 为 `b5b4ef78383677004719e1b532171c45c1dc07d3cd233b87f2ea2eb3491f43d2`；arm64 切片位于容器偏移 22347776，长度 17898656 字节。

未找到可采用的官方源码仓库。官方文档提供功能行为，已安装程序提供静态证据；Thermo 使用 AppKit、Vision、ScreenCaptureKit 独立实现。未把反汇编伪代码称作原始源码，也未嵌入 PixPin 的程序、模型、账号服务或资源。

[REA 截图字符串证据](rea-screenshot-evidence.json) 记录 Hopper 的返回值、地址、目标摘要与覆盖限制。其中出现 `ScreenShotDirect`、`ScreenShotView`、`ScreenShotBgLayer` 等 Qt/C++ 类型名，只能确定这些字符串在该程序中，不能证明具体算法或运行效果。

长截图匹配拒绝无法找到可靠重叠或内容过于单一的帧，不会自动硬拼接；当前上限是 8000 万输出像素，尚未达到 PixPin 文档描述的超长截图能力。

入口：Thermo 菜单与菜单面板的取景器菜单。默认 `⌥⌘3` 截图，`⌥⌘4` 贴出剪贴板；冲突时仍可用菜单。长截图从菜单选择区域，在预览窗口点开始后滚动目标内容，停止后进入编辑/贴图。

`CaptureCore` 只供用户态应用使用，不链接 root helper。截图、OCR 与图像处理不发送网络请求。默认截图打开贴图；主动配置后，新截图会按设置复制或保存。取消截图不复用旧图，也不执行后续动作。文本贴图保留纯文本、RTF 和 HTML；RTF 显示移除链接及附件属性，HTML 使用独立的离线 WebKit 视图，不执行页面脚本或打开外链。

验证：`swift test --filter CaptureCoreTests`。`scripts/verify-capture-ui.swift` 把生产编辑器链接到独立 QA 应用，不启动 helper、更新器或应用控制服务。

录屏入口为“录屏…”和“录屏草稿…”。可选择快速录制或普通录制。快速模式边录边编码 MP4；普通模式保存独立图片帧、鼠标数据及 PCM 音频，停止后生成预览，录后修改直接作用于独立素材。普通模式已加入摄像头和麦克风选项；键盘图层默认关闭，启用后可选择仅快捷键或全部按键。帧率支持 5/16/24/30/60；画面最长边限制 4096 像素。动图导出可选帧率与最长边，每次最多 10000 帧；GIF/APNG 不含声音，WebP 使用 BSD 许可的 [libwebp 1.6.0](https://github.com/SDWebImage/libwebp-Xcode/tree/1.6.0)，许可证随 App 分发。

录屏草稿保存在 `~/Library/Application Support/Thermo/CaptureDrafts`；只在用户主动丢弃时删除。系统声音、摄像头和麦克风默认关闭。摄像头和麦克风仅在用户勾选并点击开始后申请系统权限，不修改系统默认设备或音量。退出应用时会等待录制收尾；导出中会阻止退出。正常完成的草稿可重新打开；分片 MP4 已通过独立编码进程的 SIGKILL 测试：本次 10 秒合成素材恢复并解码出 8 秒，尚未落盘的尾部不保证恢复。实际 ScreenCaptureKit 录屏与系统音轨的强制中断恢复仍待验收。

原生预览已能显示并播放测试视频，剪辑起止、倍速和动图格式控件可操作。保存面板仍需前台验收：自动化观察中 QA 一直非激活，保存面板不是键盘窗口，虽然目录可写、文件类型与目标 URL 有效，保存按钮仍不可用；不能把后台导出测试当作该面板已通过。

普通模式的轻量/标准画质使用 JPEG，原始画质使用 PNG；预览最长边 1280 像素、最高 24 FPS，导出 MP4 时使用捕获尺寸和帧率（最长边 4096）。裁剪和标注不覆盖原始帧；标注编辑器为当前标注组设置共同的显示起止时段。修改预览后会保留剪辑起止值。预览生成或导出可取消，已保存素材会保留。

普通素材目录含 header.json、图片帧、frames.jsonl、pointer.jsonl、可选的 system-audio.caf 和 edits.json。帧队列最多保留 4 个待编码缓冲，过载时丢帧并显示计数；单份日志读取上限 128 MiB，动图导出仍限制 10000 帧。正常停止使用实际停止时间；中断恢复仅使用已落盘的完整日志和图片帧，不保证恢复队列尾部。`scripts/verify-recording-recovery.py --mode normal` 已验证强制中断后的素材可以重建并解码视频。

摄像头使用独立的 camera/ 帧目录，沿用屏幕的暂停时间轴，录后可隐藏、镜像、调整大小、放在四角或改成圆形。麦克风保存在 microphone.caf，输入会转成 48 kHz 双声道 PCM；系统声音和麦克风的增益分别保存，混音只作用于导出，不改原始音轨。旧的编辑文件缺少这些字段时使用默认值。真实设备的采样时钟通过 AVCaptureSession 的同步时钟转换到主机时钟，实际硬件同步仍待验证。

键盘事件保存在 keyboard.jsonl，沿用同一暂停时间轴。旧素材没有该文件时仍可打开。采集默认关闭，开启后默认只记录快捷键及方向/回车等功能键；普通键需选择“全部按键”。监听使用 session 层的只读 tap，停止或启动失败时移除，不改变或拦截按键。系统启用安全输入时不读取键名；不启用 root/HID 监听，也不关闭安全输入。键名按当前键盘布局生成，不从事件中读取整段 Unicode 文本。

录后可选择隐藏、仅显示快捷键或显示全部已录按键，并调整显示位置、时长和大小。先前只采集快捷键的素材无法还原未采集的普通键。实际输入监控授权、真实安全输入状态和 tap 生命周期仍待实机验收；合成键名验证不等于已捕获真实键盘。

标注效果及对象编辑的验证见 [annotations-validation.json](annotations-validation.json)。效果作用于当前合成画面，橡皮擦恢复标注前的底图；普通录制中恢复的是屏幕与摄像头合成后的画面。原始素材保持不变。智能擦除尚未接入，不使用 PixPin 的私有模型。

贴图会保存在 `~/Library/Application Support/Thermo/Pins`：`library.json` 记录分组、窗口状态与历史，每个不可变快照分别保存底图 PNG 和可编辑标注。每组默认保留 10 张已关闭贴图，可调为 0–100；关闭与销毁分开。普通关闭可恢复，销毁或清空会移除保存的数据。跨重启保留标注对象，撤销栈不跨重启保存。

“贴图分组与历史”入口可创建、切换、改名、设置颜色标签、排序、移组、删除分组或把其贴图迁往其他组。底部显示/隐藏/关闭和恢复最近关闭操作作用于当前显示的组。颜色标签用于管理列表，尚未改变窗口阴影颜色。文本、文件和颜色类型另存 content.json，清单保存类型标记；旧的纯图像快照仍可读取。原文件按路径及书签引用，不复制或修改文件内容。

LaTeX 使用随包分发的 MathJax 4.1.3 与 TeX 字体数据，在 JavaScriptCore 内执行，不依赖 Node、TeX 安装或 CDN。支持数学片段及随包启用的扩展，不是完整的 TeX 文档编译器。公式源码和样式保存在类型快照，SVG 使用矢量路径，PNG 预览按固定 2 倍分辨率生成；Word 可编辑 DOCX 导出已接入，Microsoft Word 本机验收仍待完成。

“截图快捷键与动作”可配置动作名称、作用域、按键和菜单显示。默认保留 `⌥⌘3` 截图、`⌥⌘4` 贴图；菜单标签使用实际注册状态，不再固定显示默认组合。全局绑定使用普通系统热键注册，贴图局部绑定只在本应用的贴图窗口内分发，不收集全局输入文字。

导入只改变待应用草稿；点击“应用”后保存并注册。配置限制 128 项、64 KiB，重复手势按作用域检查；同手势的局部绑定在贴图获得焦点时优先。文本编辑器保留普通输入。注册/保存失败保留原设置，释放结果不确定时停用回调并提示重启。JavaScript 已有独立执行进程及顺序原生调用，详见 [脚本说明](scripts.md)；已接入 CLI 运行、动作、查询与取消；完整 PixPin API 仍待继续。

“截图保存与后续动作”可配置快速保存目录、自动副本目录、PNG/JPEG/TIFF、JPEG 质量、文件名模板，以及截图后的动作顺序。自动副本默认关闭，动作默认仅“打开为贴图”。开启自动副本后，仅在本次区域截图成功取得图像时额外保存；导入图片、剪贴板贴图和恢复历史不会触发。普通手动保存可选择成功后复制图像。

选定截图后的动作支持复制 PNG、复制本地 OCR/条码结果、快速保存、打开贴图，可移除、排序；后一个剪贴板动作会替换前一个结果。自动副本先执行。执行使用截图开始时的设置快照；失败后停止后续步骤，保留已经完成的复制和保存，并尝试打开本次截图供用户继续操作。空 OCR 结果报错，不清空已有剪贴板。处理期间防止重入，并阻止中途退出造成保存未收尾。

快速保存不弹面板，默认以时间、宽高命名，可用 `$yyyy$/$MM$` 建子目录，支持 `%uuid%` 与 `%os%`。所选格式决定扩展名。已有文件不覆盖，自动追加编号；JPEG 将透明区域合成到白底。自动写入采用独占临时文件及原子发布，子目录不跟随符号链接。不会自动清理已有文件。

保存配置位于用户态 UserDefaults 的 `dev.thermo.capture.save.v1`；损坏配置会报错并阻止自动处理，需显式重新应用。导入只生成草稿，点击应用才生效；导出不携带本机的文件夹授权书签。当前尚不支持手动保存默认目录/最近格式记忆、保存通知、窗口标题/进程名变量、环境变量及旧副本清理。
