# 应用和本地文件搜索验收

当前为发布候选源码，尚未上线。范围为应用和本地文件名搜索，不含文件内容搜索。

搜索在用户进程中运行，使用系统 SQLite FTS5 和 FSEvents。应用读取包元数据；文件读取名称与文件系统元数据。默认无文件目录，用户须自行添加；目录范围、排除规则、隐藏文件、别名、收藏和历史保存在本机专用索引。搜索模块不链接到 root helper。

## 已验证

- 本机 Swift 6.4 / macOS 27 SDK：搜索核心及 App 专项 14 项通过；第一轮完整回归 2,018 项通过。
- 专项覆盖中文与拼音、别名、缩写、拼写错误、排序、候选上限、取消查询、旧结果隔离、稳定选择、忽略规则、离线目录、实际文件事件新增/改名/删除和重启恢复。快捷键覆盖冲突时保留原注册、重复按键和释放。
- 自有 10,002 文件 CLI 夹具通过：索引约 1.1 秒、索引约 16.8 MB；查询 P50 约 125 ms、P95 约 365 ms，包含 Debug CLI 进程启动，不代表 App 输入响应时间。文件内容未变，内容专用标记不能搜到。
- App 目录刷新与文件扫描分开；搜索窗口只请求轻量应用元数据刷新。

重跑 CLI 验收：`python3 scripts/verify-local-search.py /path/to/thermo --output result.json`。默认使用自有一万文件目录和独立索引，完成后移除夹具。`scripts/verify-local-search-ui.swift` 使用生产搜索控制器，在独立应用标识与私有索引中进行原生窗口验收，不接管安装版或硬件控制。
